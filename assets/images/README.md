# Carpeta de Imágenes y Logotipos de Family Dent

Coloca aquí los archivos gráficos de tu negocio para que la página los muestre de forma automática y local:

### 1. Logotipo:
- **Nombre recomendado:** `logo.png` o `logo.svg`
- **Ubicación:** `assets/images/logo.png`
- La página web ya está configurada para buscar y mostrar este archivo en el encabezado (header) y pie de página (footer). Si el archivo aún no existe, el sistema mostrará automáticamente un icono dental elegante de respaldo.

### 2. Fotos de la Clínica y Dentistas:
- Puedes agregar fotos reales de tu consultorio, doctores y pacientes satisfechos en esta misma carpeta, por ejemplo:
  - `clinica-interior.jpg`
  - `dentista-atencion.jpg`

### 3. Formatos recomendados:
- **Logotipos:** PNG transparente o SVG (máxima nitidez).
- **Fotografías:** JPG o WebP (optimizadas para web, peso menor a 500 KB para máxima velocidad).
